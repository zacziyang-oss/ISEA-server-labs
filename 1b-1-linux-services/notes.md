Reflection questions and my answers: 

Q1 What is the role of a firewall in managing services ?

To manage which servers are allowed to communicate with other devices. Even if a service such as Apache or SSh is running correctly, users cannot access it unless the firewall allows traffic through the appropriate ports.
This demonstrates that a service work and making it accessible are two different task, The firewalls helps administrators control access to services and reduce unnecessary exposure to the network. 

Q2 How did SSH access deepen your understanding of Linux as a server? 

Before using SSH, i viewed Linux as an operating system. After successfully connecting to another sustem through SSH it helped me to understand how Linux can 
function as a server that provides services to other computers across a network. The activity also showed why command line skills are important. 
Many servers do not have a graphical interface, so administrators must be able to manage systems remotely using terminal sessions. Using SSH made Linux feel more like a real server environment rather than 
just another operating system. 


Q3 Why is file compression important in server contexts ? 

Initially, i saw file compression as a way to save storage space. Through using tar and zip, i learned that compression is also important when transferring files across a network. Compressing files reduces the amount of 
data that needs to be transmitted, which can save time and bandwidth. it also makes it easier to package groups of files into a single archive, which simplifies backups and file transfers. 


Q4 How does user privilege Management help secure Systems ? 

Working with user and permissions demonstrated that not every user should have the same level of access. 
I learned that user privilege management exists  to limit what users can change and reduce the impact of mistakes or unauthorized access. By giving users only the permissions they need, administrators
can better protect important files and services This reflects the principle of least privilege, where access is restricted to only what is necessary for a task.

Q2: Compare software installation methods. Saas vs binaries vs repositories vs source code: 

Saas ( google docs ) is when you need to work from other devices, or you are working with others. but the disadvantage is that to need to stay online and your data lives on someone elses servers 

Binaries ( .deb file, i installed legcord ) advantage is that it lets me install software that isnt in the ubuntu repositories. It is also prebuilt so i dont have to compile it myself.
Disadvantage is that when you need to update it you cant just run "sudo apt upgrade" but download the latest version and install it again

Repositories: The advantage is that its quick and simple to install just run 
"sudo apt install ______" but the Disadvantage is that it is limited and the versions are usually older that the newest release because packages are tested before they are added

Source_code : Advantage is that it is highly customisable bacause you build it yourself,
Disadvantage is that it takes more time and knowledge and bigger programs can take a long time to compile and you would have to install all the dependencies yourself and just like the .deb install there are no auto updates.





Q3: What are the pros/cons of each method from user and developer perspective 

From the users perspective the most convinent methods would be the ( SaaS and repos ) but you get less control, the most control out off all the methods would be Source code but it takes more effort and skill. 

From the developer perspective methods like ( Saas and binaries ) cost the most to run and support. Handing the work to others ( Repos, source ) is cheaper but you would lose control over how the software reaches the user
